# 特殊画法 DXF 识别优化与实测（2026-11-10）

## 使用范围及结论

本分支以 `dwg-reader-geometric-hardening` 为基线，对真实上传的三张特殊画法 **DXF** 做源码修正，并执行 `assemble` 端到端验证；另外用办公楼原图和大型测试图做回归测试。没有人工逐构件真值，本报告列出的 **输出数量不能代表 Precision/Recall/F1，也不能证明每个候选属于正确类别**。

### 数量对比（基线 → 修改后）

| 图纸 | 墙 | 柱 | 门 | 窗 | 房间 |
|---|---:|---:|---:|---:|---:|
| 艺术楼－全在一个图层 | 0 → 194 | 0 → 57 | 0 → 8 | 0 → 0 | 0 → 5 |
| 艺术楼－图层混乱 | 67 → 58 | 7 → 7 | 0 → 15 | 0 → 27 | 3 → 4 |
| 会所－图层混乱 | 41 → 37 | 59 → 59 | 58 → 58 | 1 → 58 | 2 → 8 |
| 办公楼（回归） | 31 → 31 | 38 → 38 | 30 → 30 | 32 → 32 | 21 → 21 |
| 测试-二维DWG（回归，上一版 hardened 报告） | 309 → 309 | 67 → 67 | 65 → 65 | 2 → 2 | 36 → 41 |

- “全在一个图层”的 **5444 个实体全部在图层 0**，旧逻辑既排除图层 0，又发生小范围裁剪。新代码在这种情况下保留完整模型空间并开启几何候选路由。**194 墙、57 柱都标为 uncertain 和 needs_review**：因为同一层也有家具、尺寸、装饰线，不能视为高准确率结果。窗保持为 0，原因是缺少可独立验证的窗块/宿主墙证据；未经验证的全层平行线在初期实验中出现大量疑似误检，因此没有直接采用。
- “艺术楼图层混乱”识别 `_DBLK/_DBLK1` 与 `_WBLK`：门通过块内开启弧，窗通过独立四线块几何，并对多画法候选去重。**27 个窗是候选实例数**，没有人工核验。
- “会所图层混乱”中的 `$WinLib2D$00000001` 块有 **56 个参照**，块内的两根长线加两根短线构成窗框；原白名单未覆盖。新版本经块几何验证后输出 **58 个窗实例，其中 58 个 uncertain，45 个 needs_review**（包括未确认宿主墙情况）。墙由 41 改为 37 与新洞口参与跨洞口归并有关，不能简单视为准确率提升或降低。
- 会所房间数 2→8，但其中 **4 间的几何面积小于 1 m²**，新代码保留候选并明确标注 `area_warning`、`needs_review`，不将其当作可直接用于算量的可靠结果。
- 大型测试图房间输出数 36→41，仍可能低于历史数量参考范围；未进行几何真值精度验证。

### 主要代码变更

| 文件 | 调整 |
|---|---|
| `src/dwg_reader/recognition/unlayered.py`（新增） | 识别真正的单图层非语义绘图，仅在该条件下放开图层 0；生成审慎的候选路由与禁止裁剪策略 |
| `recognition/nodes.py` | 加载时图层异常回退；门窗未知块的块内几何检查；房名来源取并集；单层墙结果强制待复核；候选源实体类型保真；小面积房间标记疑点 |
| `recognition/rooms.py`、`recognition/labels.py` | 允许汉字间空格、书库/配电所/办公/卧等名称及更多房名锚点，保留非房名排除词 |
| `recognition/elements.py` | 传递独立窗块结构证据，允许通用块族窗口识别 |
| `recognition/unified.py` | 保留未知窗块原始类别；经内部几何验证的窗不套用门宽上限；修正源实体类型 |
| `recognition/openings.py` | 有独立块几何证据的窗在宿主墙缺失时保留为 pending/uncertain，而不是静默删除 |
| `tests/test_unlayered_drawings.py`（新增） | 单图层安全回退、普通图不误入单层模式、房名合并、陌生门窗块需结构证据、窗宽阈值与类型溯源等回归测试 |
| `scripts/verify_user_drawings.py`（新增） | 可重跑 46 节点 DAG、导出构件数量/状态，以及待复核构件几何与证据 |

### 测试结果

`277 passed, 5 skipped`。跳过项依赖 ODA DWG 转换器、字体资源或外部 profile/测试文件；已上传的 5 张 DXF 都执行了完整 `assemble`。其中三张特殊图的逐构件审阅列表在 `reports/special_drawings/*.review.json`，包含位置、候选几何、证据及来源实体。测试状态与数量在 `reports/special_drawings/summary.json` 和 `final/*.json`；基线见 `baseline/*.json`。

运行方法（需要 Python、`ezdxf` 与 `pytest`）：

```bash
python -m pip install -e '.[dxf,dev]'
python -m pytest -q
python scripts/verify_user_drawings.py '/path/to/艺术楼-全在一个图层.dxf' \
  --out /tmp/recognition.json --review-out /tmp/recognition.review.json --budget-ms 1200
```

### 下一步验收仍需

1. 对这三张图分别人工抽样标注墙/柱/门/窗/房间，测量位置匹配后的 TP、FP、FN，不能只看数量。尤其先复核单层图 194 墙和 57 柱的误检。
2. 单图层的“无块窗”需独立的上下文验证算法（窗所在墙缺口、截面、线束与尺寸证据），当前仍可能漏检，不能为追求数量直接接受全部平行线。
3. 对会所房间边界做局部诊断，修正面积小于 1m² 的可疑空间；不要把新多出的房间直接用于精确算量。

此包只包含源码、测试与报告，**不重复分发原始用户 CAD 文件**。DWG 仍需要有效的 DWG→DXF 转换器；本轮验证使用了用户随后上传的 DXF 版本。
